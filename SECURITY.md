# Security policy

## Supported versions

Security fixes go into `master` and the next release. Please keep to the latest image.

## Reporting a vulnerability

Please **don't open a public issue** for security problems.

Use **Security > Report a vulnerability** on the GitHub repository (a private report that only the
maintainers can see). Include:

- what is affected and the image tag or commit;
- steps to reproduce, or a proof of concept;
- what an attacker could do with it.

We aim to answer within a week and to ship a fix as soon as we can.
