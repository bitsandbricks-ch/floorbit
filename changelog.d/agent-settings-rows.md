### Changed

- An agent's Settings tab shows the address in the hall, the telemetry port and the log level first;
  metrics, buffer and logging details fold under Advanced, and the shared addresses (VRRP) only show
  once there is a second agent. Values say where they come from only when it isn't the default, the
  limits set in the hall are described in words, and changes are saved through the same save bar as
  Settings.
