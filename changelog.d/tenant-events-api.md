### Added

- Events inside one install: add an event in planning (empty or from a copy of another event's
  floor plan), make an event live, and copy parts of a plan (halls, seats, inventory, cables, power,
  services, schedule) into another event with a preview, by merging or replacing. Pages pick an
  event with `?event=<id>`. The event switcher in the menu comes next; see `docs/tenancy.md`.
