### Added

- Floor plan editor: a path row can be in several pieces, so one row can run round a U and on through a line of seats inside it while keeping one run of seat numbers.
- Floor plan editor: each row's letter can sit beside seat 1, after the last seat, at both ends or be hidden, and can be dragged anywhere on the plan; it then moves with its row.

### Changed

- Floor plan editor: the edit panel is wider (440 pixels, 520 on wide screens), its left edge can be dragged, and a seat block's fields sit in tabs: Block, Rows (a small tab per row), Seats and Items.
