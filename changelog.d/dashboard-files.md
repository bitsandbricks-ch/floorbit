### Added

- Dashboards can move between Floorbits: **Export as file** in the editor's **⋯** menu, and
  **Import** on the Dashboards page. The file holds the layout only, never secrets or seat data, and
  an imported dashboard is not public until someone says so.
- Plugins can ship ready-made dashboards of their own widgets (`dashboards:` in `plugin.yaml`).
- A tile from a plugin that is missing says which plugin it needs.
