### Added

- **Seat blocks with a letter per row:** a new block can name its seats by row (`E-1`, `E-2` … `F-1`) instead of block name and number, with the row letter before seat 1, after the last seat, on both ends or hidden. The letters show on the floor plan, the Seats view, the kiosk, the hall view and the seat finder.
- **Add several seat blocks at once:** set how many, below or to the right, and the gap; row letters and single-letter block names count on.
- **R** turns the selected seat block a quarter (**Shift+R** the other way), and the numbers turn with it.

### Changed

- A seat name is never given twice: a block that would repeat a seat from any hall is refused and says which seat clashes.
