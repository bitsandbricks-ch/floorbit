### Added

- Demo mode: `FLOORBIT_DEMO=1` (or Settings > Plugins > Demo data) fills Floorbit with a made-up
  hall: 15 switches, four seat blocks, players on documentation IPs, traffic, a flapping switch, a
  half-duplex port and a port with errors. Every page says "Demo data" while it's on. On an empty
  floor plan the hall is laid out automatically; nothing placed by hand is moved. See `docs/demo.md`.
- The pull request screenshots now use demo mode, so they show a filled floor plan.
