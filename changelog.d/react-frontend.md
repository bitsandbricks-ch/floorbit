### Added

- A React frontend (`frontend/`: React, TypeScript, Mantine, TanStack Query), set up like Hubra's.
  The dashboard and Settings > Plugins are the first pages in it; the other pages follow one at a
  time. Flask stays the API and serves the pages, with the same themes and sign-in. The Docker
  image builds it.
- German: the React pages come in English and German, picked from the browser and changeable in
  the user menu.
