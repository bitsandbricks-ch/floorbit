### Added

- Wi-Fi view: `/wifi` shows each access point's channel use, clients and channel on the floor
  plan, per band, with access points on the same channel near each other flagged. From the UniFi
  plugin (new `wifi` plugin area, `wifi_aps()`) or any plugin with `uses: [wifi]`. Client counts
  only. The demo data has nine access points. See `docs/wifi.md`.
