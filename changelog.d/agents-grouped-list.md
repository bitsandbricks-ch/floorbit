### Changed

- Settings > Local agents is one list for any number of agents: four figures on top (online, need
  a look, failover ready, up to date), search and filters, then the agents grouped by agent group
  with the ones that need a look first. Each row shows the agent's role, devices, syslog lines per
  second, a one-hour load line, its version and its worst problem. A row opens the agent in a side
  panel beside the list, where a blocked switch login can be cleared. "Update N agents" shows the
  agents on an older version.
